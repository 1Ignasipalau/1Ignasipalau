# Hola, soy Ignasi 👋

Desarrollador full-stack titulado en DAM (Desarrollo de Aplicaciones Multiplataforma). Mi punto fuerte es el frontend con React y React Native, y he trabajado también en backend (Node.js, FastAPI, C#/ASP.NET Core) y bases de datos SQL.

En mis prácticas desarrollé herramientas internas para producción, laboratorio, stock y logística. Después trabajé como freelance digitalizando un negocio real y construyendo productos propios.

## En qué trabajo
- **GreenApp**: app móvil de bienestar que conecta usuarios con gimnasios y profesionales de nutrición y entrenamiento.
- **Beta 3M**: app de apuntes con IA para estudiantes, con texto, dibujo y gráficos en un mismo editor.
- **Sorella**: web con API propia para un negocio de estética real.

Los repositorios se irán publicando a medida que los proyectos estén listos.
